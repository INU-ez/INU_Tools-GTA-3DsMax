# Руководство INU Tools для 3ds Max

[English](USER_GUIDE.md) · [Описание и совместимость](README_rus.md)

Руководство описывает установку, импорт и экспорт моделей, материалы, карты и анимации в 3ds Max. Названия кнопок приведены на английском: язык можно изменить в **Setup → Language → Русский**.

## Установка и обновление

1. Распакуйте INU Tools в отдельную папку.
2. В Max выберите **Scripting → Run Script…** и запустите `inu_launcher.ms`.
3. На вкладке **Utilities**, в разделе INU Tools нажмите **Install INU**. Для обновления замените файлы исходной папки и нажмите **Update INU**.
4. Дождитесь окончания установки и перезапустите Max.

Если NumPy отсутствует, установщик скачает его с PyPI; для этого нужен интернет. При отсутствии pip установщик загрузит временный pip и удалит его после установки. После установки инструменты работают локально. Если используете несколько версий Max, выполните установку в каждой версии, которой требуется NumPy.

Поддерживаются Max 2023–2026; проверки рабочего интерфейса выполнены в Max 2026. Для нативного плагина используется бинарник соответствующего года из `plugins/<год>/`.

## Первое открытие

Откройте лаунчер INU Tools и выберите нужный раздел. **DFF IO** предназначен для отдельных моделей, **Map IO** — для карты с IDE/IPL/IMG, **IFP IO** — для анимаций. Выберите целевую игру **SA**, **III** или **VC** и платформу **PC** или **Mobile**. При импорте режим **Auto** в файловом окне определяет игру по версии RenderWare.

Перед работой сохраните исходную сцену отдельно. Переключение языка не меняет имена объектов, материалов, текстур и файлов.

## Импорт моделей и текстур

1. Откройте **DFF IO**.
2. Под кнопками Import / Export выберите **Import materials → Standard** или **GTA Material**. Выбор относится к вновь создаваемым материалам DFF.
3. Включите **Auto TXD**, если нужны текстуры.
4. Нажмите **Import**, выберите файлы и проверьте параметры справа.
5. Нажмите **Import** в файловом окне и прочитайте итоговый отчёт.

Импортируются только выбранные файлы. Поддерживаются DFF, COL, CST, TXD, IDE и IPL; каждый формат обрабатывается своим импортёром. Выбор IDE/IPL в обычном импорте не заменяет загрузку ресурсов карты через Map IO.

**Standard GTA SA model (vanilla)** включает обработку стандартной SA-геометрии со сваркой и острыми рёбрами. Для авторских моделей оставляйте этот режим выключенным, если не требуется именно такая обработка. **Import 2DFX** добавляет эффекты из DFF.

### Как находятся текстуры

Auto TXD ищет изображения по имени текстуры в папке DFF и подпапках: PNG, DDS, TGA, BMP, JPG/JPEG и TIFF. Ближайшие папки имеют приоритет. Отдельные изображения используются раньше текстур из автоматически найденного TXD; TXD заполняет недостающие текстуры. Явно выбранный при том же импорте TXD имеет наивысший приоритет.

Если модель без текстур, проверьте имена изображений и их расположение либо выберите нужный TXD вместе с DFF. Выбор типа материала сам по себе не создаёт отсутствующие изображения.

### Импорт нескольких моделей

Выберите несколько файлов через Ctrl/Shift. Появятся процент, счётчик обработанных файлов и текущее имя. Прогресс обновляется между файлами: большой DFF может обрабатываться долго без изменения процента.

**Cancel** останавливает импорт перед следующим файлом. Уже импортированные объекты остаются в сцене; отмена не откатывает партию. При повторном импорте не выбирайте уже загруженные модели, если не нужны дубликаты.

## Экспорт моделей

1. Выделите нужные модели и откройте **DFF IO**. Проверьте сводку DFF / LOD / COL.
2. При необходимости выполните **Pre-export check**; **Audit models on export** проверяет DFF после записи.
3. Нажмите **Export** и выберите папку, целевую игру и нужные форматы DFF / COL / LOD / TXD в параметрах окна.
4. Проверьте итоговый отчёт и результат в игре.

**Single DFF** предназначен для одного итогового DFF и не совмещается с **All → IMG**. В IFP IO кнопка **Export skin (single DFF)…** открывает экспорт одного персонажа или транспорта с этим режимом.

Для итогового сжатия текстур выбирайте **Numpy**. **Numpy fast** подходит для быстрых проверок, но может давать артефакты на резких границах прозрачности. Экспорт Mobile записывает native-геометрию, однако TXD создаётся в PC-формате и требует отдельной конвертации PVRTC/ETC для устройства.

## GTA и COL материалы

**Standard** создаёт стандартный материал Max с GTA-свойствами INU. **GTA Material** использует встроенный оригинальный `GTA_Mtl` Kam/GoldFish. Отдельная установка Kam’s не требуется; уже установленные оригинальные классы используются повторно.

В редакторе материалов доступны **GTA Material**, **GTA COL Surface** и **GTA COL Shadow**. Для DFF задаются цвет, альфа, карты и эффекты; для COL — поверхность и связанные параметры коллизии. Окно **GTA Material** в INU содержит инструменты работы с материалами и GTA-свойствами.

Старые материалы INU остаются доступными для ранее сохранённых сцен. Перевод и компактная компоновка не заменяют их классы и не меняют назначенные карты. Подпись пустой карты переводится; имя назначенной карты сохраняется.

**DK Normal Map**, эффект 6, поддерживает импорт/экспорт нормалей, отражений и силы отражения через блок `0x133`. Отображение в игре требует стороннего DK-плагина. Для III/VC учитывайте ограничения SA-эффектов и UV-анимации.

## Карты и архивы

IDE описывает модели и их ID, IPL — экземпляры и размещение, IMG хранит ресурсы. Один DFF не содержит размещение всей карты.

1. Откройте **Map IO → Import** и укажите **Game folder** — корневую папку игры.
2. Добавьте нужные IPL в список кнопкой добавления файла или папки.
3. Выполните поиск **IMG** и **IDE** для выбранных IPL. Эти кнопки находят ресурсы и ничего не импортируют.
4. Выберите, загружать ли **LOD**, **TXD** и **COL**, затем нажмите **Import**.

При импорте по IPL модели размещаются по его данным. При импорте по IDE определения моделей загружаются сеткой. Перед экспортом карты проверьте ID, связи LOD и пути ресурсов; используйте **ID Manager** для назначения ID и поиска конфликтов. Параметры экспорта карты и IMG находятся в Map IO.

## Педы и анимации

1. Импортируйте DFF персонажа через DFF IO.
2. Откройте **IFP IO → Characters** и импортируйте IFP в библиотеку анимаций сцены.
3. Выделите скелет, выберите анимацию и нажмите **Apply**.
4. Для редактирования через IK нажмите **Add IK Rig**. Для перемещающейся анимации выберите **Root motion (walk/run)** перед созданием рига.
5. После редактирования выполните **Bake & Clear IK**, затем экспортируйте IFP.

Риг SA содержит 13 боксов: кисти и стопы, локти и колени, плечи, спину, голову и корень. Боксы локтей/колен управляют направлением сгиба. Цвет, размер и видимость контролов настраиваются в панели. **Add Ground Plane** подключает ограничения стоп.

Bake & Clear IK записывает вычисленную анимацию на кости GTA и удаляет контролы. Этот шаг нужен перед экспортом IFP, чтобы результат движения IK попал в файл. Для старого рига сначала выполните Bake & Clear IK. Если старая версия уже исказила исходную позу, импортируйте исходный DFF заново: запекание сохранит искажённую позу.

**Export** сохраняет IFP. **Add** добавляет анимации в существующий пакет или заменяет совпадающие по имени без учёта регистра; остальные анимации сохраняются. Перед изменением игрового пакета сделайте его копию.

## Другие инструменты

| Окно | Назначение |
|---|---|
| Vehicles | Иерархия фреймов транспорта, пары `_ok` / `_dam`, проверки машины |
| 2DFX | Эффекты DFF и параметры частиц `effects.fxp` |
| Paths | Compiled NODES SA, точки, связи и атрибуты графа |
| Zones | Импорт и правка `map.zon` боксами, экспорт с `.bak` |
| Water | Импорт, создание и экспорт воды |
| X Radar | Инструменты создания радара |
| Check | Проверки сцены, файлов и связей IDE/IPL, поиск текстур |

При работе с Compiled NODES сохраняйте связанные районы: изменение ID точек может требовать пересчёта внешних ссылок. Не обходите проверку графа при экспорте.

## Ошибки и диагностика

| Симптом | Что проверить |
|---|---|
| После установки инструменты не открываются | Перезапустите Max; при необходимости выполните Update INU из актуальной исходной папки |
| NumPy не установлен | Доступ к PyPI и отчёт Install / Update INU именно в используемой версии Max |
| Текстуры не найдены | Auto TXD, имена изображений, папку DFF и выбранный TXD |
| Процент импорта временно не меняется | Обработка текущего файла; обновление и отмена выполняются между файлами |
| Во вьюпорт нельзя перетащить файл | Нативный плагин соответствующего года; используйте Import или перетаскивание на окно INU |
| Экспортированная анимация отличается от IK | Выполнен ли Bake & Clear IK перед экспортом IFP |

При ошибке сохраните отчёт операции и сообщения MAXScript Listener. Журнал этапов обычного импорта находится в `%LOCALAPPDATA%\INU_Tools_Max\freeze_trace.txt`; новый запуск записи заменяет предыдущий журнал. Настройки находятся рядом в `settings.json`.

Для сообщения об ошибке укажите версию Max и INU, игру/платформу, действие, параметры и файл, на котором ошибка воспроизводится. При массовом импорте полезны число файлов и последнее имя в прогрессе. После краша сохраните дамп и журнал до повторной попытки.

## Документация Blender и ограничения

[INU Tools для Blender](https://github.com/INU-ez/INU_Tools-GTA-Blender) — дополнительный источник сведений об общих форматах GTA, ID, LOD и правилах движка. Для действий в Max используйте это руководство: материалы, выделение, иерархия, контролы IK и файловые окна зависят от приложения. Blender-specific Texture Bake, geometry nodes и живые превью в Max не перенесены.

Подробности проверок и известных ограничений находятся в [журнале переноса](MAX_TODO_2026-09-28.md). Проверки Max 2026 не гарантируют тот же результат в Max 2023–2025 или в игре.
