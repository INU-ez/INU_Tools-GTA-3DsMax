# INU Tools for 3ds Max

- Изменения сцены через `pymxs` выполняются в основном потоке Max. Не запускать фоновый `faulthandler.dump_traceback_later`: причина и ограничения расследования описаны в `docs/MAX_TODO_2026-09-28.md`.
- Проверки Python: `python -B -m unittest discover -s dev/tests -q`. В ограниченной среде задавать `tempfile.tempdir` внутри игнорируемой `dev/tests/e2e/.tmp-tests/`; не менять тесты ради недоступного системного TEMP.
- Нативные сценарии лежат в `dev/tests/e2e/`. Проверять `success` в JSON, а не только код выхода Max Batch. Игровой каталог для теста массового импорта задаётся через `INU_TEST_GAME_ROOT`.
- Тестировать на отдельных сценах и процессах. Для GUI использовать временный `ADSK_3DSMAX_USERSETTINGS_DIR`; отключать сохранение INU-настроек в тестовом процессе.
- Перевод и правки редактора материалов должны сохранять параметры, class ID, назначенные карты и их имена. Оригинальные Kam-файлы сохранять; перевод выполнять общим адаптером `i18n_native.py` для оригинальных и legacy-классов.
- Qt: общий фасад `inu_max/qt.py` поддерживает PySide2 (Max 2023–2024) и PySide6 (2025–2026). Прогресс импорта обновлять между файлами, без фонового доступа к сцене и вложенного `exec()`.
- ZIP и коммиты создавать только по просьбе пользователя. Подробности реализации и пределы проверок записывать в документацию проекта.
